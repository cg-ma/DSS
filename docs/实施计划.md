# 间接提示注入动态防御系统严格实施计划

## 0. 使用方式

本文档是执行手册，不是论文综述。实施时按阶段顺序推进，不跳阶段；每完成一个阶段，必须满足“阶段验收标准”后再进入下一阶段。

本项目主线严格围绕三个工作重点：

1. 敏捷感知模块：重叠滑动窗口 + 轻量化类 BERT 分类器 + 困惑度过滤器，解决前置检测延迟高的问题。
2. 混合专家双环验证：反射式意图修正 + 语义一致性 + 逻辑对齐 + 数据泄露风险专家，解决单一模态防御盲区。
3. 动态风险仲裁：依据感知层风险标签动态调整通过阈值和审计深度，解决安全性与可用性平衡问题。

执行规则：

1. 每个阶段只做本阶段列出的内容，除非前一阶段验收失败需要返工。
2. 数据集构建只作为实验支撑，不写成主要创新点。
3. 所有攻击样本必须来自网页、文档、邮件、搜索结果等外部检索源，不做用户直接输入式提示注入作为主实验。
4. 每个实验必须输出机器可读日志、CSV 表格和可复现实验配置。
5. 任何 API Key、模型 Key、私有 URL 不允许硬编码在脚本中。

| 阶段 | 目标 | 主要产物 | 进入下一阶段条件 |
| --- | --- | --- | --- |

每条样本至少包含：

```json
{
  "case_id": "web_hidden_0001",

  "user_query": "请总结这篇网页的主要内容",
  "external_content": "...",
```
